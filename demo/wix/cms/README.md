# CMS seed files

Upload each CSV in the Wix dashboard: CMS → Create Collection → **Upload CSV**.
Name the collections exactly `Services` and `Stats` (that name is the collection id the site queries).
After import: collection ⋯ → Permissions & Privacy → "Site content", view: **Anyone**. Then Publish.

`icon` in services.csv is a key the site maps to an SVG (zap, droplet, flame, waves, wrench, shield).
