Carousel arc — default narrative

Reference, not law. Default 5-slide story: HOOK → PAIN → STEPS → RESULT → JOIN. If the post fits a different arc better (case study, listicle, before/after, announcement), the AI may design its own arc. Two invariants only: slide 1 = scroll-stopping hook, last slide = CTA. PAIN / STEPS may span 2–3 slides each; HOOK and JOIN stay single.

01 / COVER
HOOK
  • One hero word
  • Subline: pain + payoff
02 / PROBLEM
PAIN
  • Name the problem directly
  • ✗-list of what breaks
03 / SYSTEM
STEPS
  • The mechanism that solves it
  • 01 / 02 / 03 numbered list
04 / PROOF
RESULT
  • Massive specific number
  • ✓-checkmark outcomes
05 / CTA
JOIN
  • Price + lock-in promise
  • Comment keyword: SITE
